# BACKROOMS (백룸)

브라우저에서 즐기는 1인칭 심리 공포 게임. 무한히 이어지는, 시드 기반으로 절차 생성되는
사무실 공간 — 누런 단색 벽지, 축축한 카펫, 형광등의 웅웅거림. 그리고
이 미로의 구조를 전부 외워버린 무언가.

**헤드폰 착용을 강력 추천합니다. 사운드가 이 게임의 절반입니다.**

## 실행 방법

```bash
npm i
npm run dev
```

터미널에 출력되는 주소(보통 http://localhost:5173)를 데스크톱 브라우저(Chrome/Edge/Firefox)로 여세요.
`npm run build`는 정적 번들을 생성하고, `npm test`는 Node에서 월드 생성 테스트를 실행합니다.

에셋 파일이 하나도 없습니다: 모든 텍스처는 실행 시 캔버스로 그려지고,
모든 사운드는 Web Audio API로 실시간 합성됩니다.

## 조작법

| 입력 | 동작 |
| --- | --- |
| 마우스 | 시점 회전 (포인터 락) |
| WASD | 이동 |
| Shift | 전력질주 (스태미나 소모, **소리가 나서 그것이 듣습니다**) |
| Ctrl / C | 웅크리기 (느리지만 조용함) |
| E | 아몬드 워터 줍기 |
| Esc | 일시정지 |

선택사항: URL에 `?seed=12345`를 붙이면 월드 시드를 고정할 수 있습니다.

## 게임 루프

- **정신력(Sanity)** 은 어둠 속에서, 그리고 그것이 가까이 있을 때 깎입니다.
  밝은 곳에서 회복됩니다. 정신력이 떨어질수록 화면 가장자리가 어두워지고,
  VHS 노이즈가 심해지고, 소리가 뒤틀리고, 디렉터(연출 AI)가 더 악랄해집니다.
  **아몬드 워터**를 마시면 회복됩니다 — 병이 어둠 속에서 희미하게 빛납니다.
- **출구**는 아주 드물게 생성되는 이상한 방입니다 (이곳에 어울리지 않는
  음이 들리면 그 방향으로 가세요). 어두운 벽 속으로 걸어 들어가면
  노클립으로 탈출 — 승리입니다.
- **죽음**은 그것에게 잡히는 것. 전체 화면 점프스케어 후 기록이 표시됩니다:
  생존 시간, 걸은 거리, 견뎌낸 공포 횟수, 찾은 아몬드 워터, 떠돈 청크 수.

## 구조

```
src/
  core/rng.js        결정론적 해시, 시드 난수, 밸류 노이즈
  world/grid.js      순수 월드 로직: 무한 청크 미로, 연결성 보정
                     (막힌 공간이 절대 없음을 보장), A* 경로탐색, 시야 판정
                     — DOM 없이 Node에서 단위 테스트 가능
  world/world.js     청크 스트리밍 렌더러: 청크별 병합 지오메트리,
                     인스턴싱된 형광등, 멀어진 청크 자동 해제
  world/textures.js  절차 생성 텍스처: 벽지 / 카펫 / 천장 / 점프스케어 얼굴
  world/lights.js    형광등 오작동(깜빡임/죽은 등), 포인트 라이트 풀, 정전 연출
  audio/engine.js    Web Audio 코어: 버스, 마스터 컴프레서, 헬퍼
  audio/ambience.js  60Hz 험 + 배음 + 미세한 드리프트, 환기구 소음, 조명 버즈,
                     동적 긴장 드론 (그리고 그것의 급정지 — 침묵은 무기다)
  audio/sfx.js       발소리, 멀리서 나는 쿵 소리, 속삭임, 그것의 소리,
                     합성 비명 스팅어
  player/player.js   포인터 락 FPS 컨트롤러, 스태미나, 소음 모델,
                     원-vs-AABB 충돌 처리; 정신력 시스템
  entity/entity.js   잠복 → 스토킹 → 추격 → 습격 상태 머신,
                     소음 기반 인지, A* 추적, "그것을 똑바로 보지 마라"
  director/director.js  연출의 두뇌: 긴장도 모델, 소형 이벤트 스케줄러
                     (깜빡임, 쿵 소리, 목격, 정전), 대형 공포 간격 제어,
                     공포 후 정적 구간
  fx/post.js         단일 패스 포스트 프로세싱: 필름 그레인, 색수차,
                     비네트, 정신력에 따라 심해지는 VHS 아티팩트
  ui/ui.js           타이틀 / 설정 / 일시정지 / 사망 / 승리 화면, 페이드, HUD
  main.js            앱 상태와 프레임 루프
```

### 월드 생성 보장

청크는 8×8 셀(셀당 4m)입니다. 내부 벽은 시드에서 결정되고, 청크 경계는
항상 열려 있으며 경계 셀은 절대 막히지 않습니다. 청크마다 보정 패스가
플러드 필로 모든 영역을 하나로 이어붙입니다 — 따라서 각 청크는 내부적으로
완전히 연결되고, 그 결과 무한한 월드 전체가 하나의 연결된 공간이 됩니다.
`npm test`가 결정론, 청크 내/청크 간 연결성, 경로 유효성, 시야 판정을 검증합니다.

### 성능

설계 단계부터 예산을 잡았습니다: 청크당 병합 벽 메시 1개 + 바닥 + 천장 +
인스턴싱 형광등 메시 1개 (청크 약 25개 로드 시 드로우 콜 수십 개 수준),
포인트 라이트 5개 풀링, 안개로 제한한 가시거리, 풀스크린 포스트 패스 1회,
청크 생성은 프레임당 1개로 분산, 멀어진 청크는 메모리에서 해제.
그래픽 프리셋(설정 메뉴): 낮음(포스트 끔, 짧은 안개) / 중간 / 높음(긴 가시거리).

## 공포 강도 조절

연출 페이스 조절 값은 대부분 `director.js` 상단(`minBigInterval`, 정적 구간,
이벤트 가중치)과 `Sanity.update`에 있습니다. 그것의 감각(청각 민감도, 거리,
속도)은 `entity.js`에 있습니다.
